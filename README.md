# Typeboard

Vue 3 + TypeScript practice app. Four pages you can extend while you learn typing.

## Pages

- **Dashboard** — computed stats, discriminated unions, exhaustive `switch`
- **Tasks** — unions, type guards, `FieldErrors<T>`, generic `sortBy`
- **Contacts** — person | company narrowing, generic search, form validation
- **Catalog** — category/stock unions, typed cart, money helpers

Start in `src/types`, then the matching view in `src/views`.

## Run

```sh
npm install
npm run dev
```

```sh
npm run type-check
```
